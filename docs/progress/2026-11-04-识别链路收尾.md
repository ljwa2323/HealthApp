# HealthApp 开发进度汇报

> 2026-11-04 · 阶段性汇报

## 总体进度

这一周集中收尾医疗单据识别链路。外部评测暴露的三类硬伤（长文超时被重试放大、用药字段静默丢失、多页 PDF 只识别首页）已全部修掉，同时把 prompt 收紧、电子截图误报、低置信格标红一起做了。识别这块在当前模型能力下基本到头，下一步准备完成AI 助手模块收尾。

## 已做完的事

1. **长文超时不再被重试放大**：vision 主循环原来 `except Exception` 把 `APITimeoutError` 也当可重试，240 秒超时 + 退避 sleep 再来一轮，narrative 文档跑了 487 秒。现在超时异常单独捕获直接快速失败，降级走 P0-1 OCR 原文；只有限流和 JSON 解析失败才重试。
2. **用药 fact 缺字段不再静默丢失**：cross_check 新增 `medication_missing_fields`，对 `kind=medication` 的 fact 强制检查 dose / frequency / route 三个属性，缺哪项挂 `missing_field` 状态，前端 fact 行角标显示"用药字段待补"，悬停看缺什么。没有让模型二次核对——第一次就漏，重试大概率编造频次。
3. **多页 PDF 逐页识别并合并**：`pdf_to_pages()` 拆页（上限 30 页），逐页 OCR + vision，facts 拼接、narrative 跨页拼接，某一页失败只记错误继续，不整份失败。grid 重建只对单页做，避免跨页切表。
4. **Prompt 收紧解决过度拆条和分条抖动**：
   - facts 粒度宁粗勿细，连续叙述整体归一条 note（手术记录从 23 条压回合理量级）
   - format 硬标准：有表格线/分列走 structured，大段连续文字走 narrative（出院小结 ho1-4 和 ho5 之前分类不一致的问题）
   - 用药 few-shot 正反例：`0.5% 氯霉素滴眼液 2支 外用 每日3次` 必须拆到 dose / quantity / route / frequency
5. **电子截图不再误报折痕/反光**：质量门加截图判定——四角亮度与全局均值差 <10 且白底占比 >0.35 时跳过 skew / fold / glare 三项物理检查，保留分辨率/模糊/亮度检查。
6. **低置信 OCR 单元格前端标红**：表格重建时每个格子带着 OCR confidence，`low_confidence_matrix()` 和展示矩阵同形状、同跳行逻辑，低置信格在表格视图显示浅粉底虚线框，悬停提示"该格 OCR 置信度低，请对照原图核对"。
7. **三种展示形态可手动切换**：分条 facts / 表格 grid / 全文 narrative，AI 自动判断默认视图，用户识别不准时可手动切。

## 实测结果

- 合成化验单 PNG：61 秒返回，分类 laboratory，4 条 fact，grid 5×4 完整，cross_check 3 verified + 1 conflict（血红蛋白单位 OCR 误读被正确报出），无 LLM 错误。
- 17 页 PDF：686 秒返回，`pdf_page_count=17`，17 页全部跑完合并出 60 条 fact + 1279 字 narrative，无一页失败。
- 手写体温单：matrix=None 正确降级，不硬切表。

## 遇到的问题与解决

- **手写体识别率上不去**：外部评测字段名认对 19%、字段值只认对 4%。打印表头能认，手写潦草药名、竖排中药方基本读不出。这是模型能力上限，继续换模型不划算，**不做自动手写识别**。
- **GLM 纠正表格后行列错位**：纠正矩阵和低置信矩阵必须复用同一套跳行逻辑（跳过坐标轴行、标题行），否则行列对不上。

## 还没解决的

- **手写体**：不做 OCR，改走人工录入方案,后续前端优化。
- **多页 PDF 慢**：17 页要 11 分钟，是逐页串行调 GLM 的代价，后续可考虑并发或分页预览。
- **facts 视图和 grid 视图双源不同步**：两份数据是模型独立输出的，用户改一边另一边不联动。目前不做映射，用户改的是自己所在视图，另一边本来就不进时间轴。
- **幻灯片类 PDF 首页**：渐变背景没命中截图判定，质量门会误报折痕/反光，不阻塞。

## 手写体的处理方案

不在 OCR 上死磕。前端加一个**语音文字录入窗口**：用户对着念病历内容，语音转成纯文字，用户自己填日期，直接作为一条 note 进时间轴。

## 下一步

- **AI 助手模块收尾**：置信度公式用真实问答数据校准；流式对话持久化压测；加用户反馈按钮（回答有用/没用）迭代 prompt。
- 手写体录入窗口接时间轴。
